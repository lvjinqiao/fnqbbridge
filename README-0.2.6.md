# fnqbbridge 0.2.6 第一阶段交付

基于本机现有 0.2.5 增量修改。未新建下载引擎、未嵌入 qBittorrent WebUI。当前工作目录不是 Git 仓库；已在 work/baselines 留存原源码备份，另附可回滚的 0.2.5 FPK。

## 本版修复

- **目录选择**：兼容直接数组、`data` 数组、`data.paths`、数组内 `path` 对象；取消选择不覆盖原值，无法识别的返回结构明确报错。
- **随时更换目录**：添加任务时可重新选择目录，或改用默认目录；经验证的选择及成功提交的手工路径写入自有 config.json，关闭窗口、刷新页面和重启后可恢复。重置按钮可清除偏好。更换偏好不移动现有任务及文件。
- **前后端链路**：前端明确发送 locationMode 和 savepath；自定义模式缺少路径时后端拒绝。UI 路径规范化后须为现有 `/volN/` 内的目录，解析符号链接并测试可写；保留内部中文和空格。验证不通过时不改成其他目录。
- **MoviePilot**：代理保持原始请求字节，不重建其 multipart，不替换 savepath、不切换目录；保留白名单参数日志。路径有首尾空白时增加提醒，不擅自修正上游请求。
- **配置**：保存端口/密码保留目录偏好；旧 0.2.5 配置无需转换。配置原子替换；升级不替换密码和端口。
- **日志**：Go 内部轮转，当前文件最大 2 MiB，保留 3 份备份；旧版超大日志在轮转前只保留尾部 2 MiB。减少正常高频查询日志，重复错误在 10 秒窗口内抑制。界面保留最近 200 条事件，打开日志页每 4 秒刷新。该界面的最近事件仍以本次进程为范围，重启前历史在轮转文件中。
- **卸载**：先停止自己的服务；向导选择“清理”或“保留”。仅对拥有标记的自有数据目录删除 config.json、配置临时文件、bridge.log 及轮转文件和 PID 标记。不递归删除任何下载路径、原生数据库或媒体库。升级回调只写所有权标记。
- **界面**：任务展示保存目录；删除确认明确标注现有原生列表残留限制。

- 不同卷路径、中文/内部空格、尾部斜杠、相对路径和越界路径校验测试通过；临时目录写入探针创建后可清理。
- 目录偏好保存、重载、清除，以及端口/密码保存不覆盖偏好测试通过；0.2.5 配置兼容测试通过。
- 磁力链接和种子文件经模拟 qBittorrent 管理接口提交测试通过；暂停/继续、查询及旧接口测试通过。
- MoviePilot multipart 原始字节一致与日志敏感字段排除测试通过。
- 日志限额、轮转数量及旧超大日志限制测试通过。
- 生命周期脚本在隔离临时目录内验证：保留配置、升级不覆盖、卸载保留/清理、无标记不清理、外部媒体文件不受影响。
- Chrome 模拟后端验证登录、选择目录并持久化、重新打开恢复、磁力提交、种子选择、自定义目录预览、设置和日志，以及桌面/手机布局。

模拟测试不等于 NAS 实机通过。尚未访问用户 NAS，也没有操作任何真实下载任务、原生数据库或下载文件。

## 实机验证步骤

1. 在应用中心手动升级 0.2.6，不卸载；确认原端口和密码保留。
2. 从飞牛桌面打开，选择实际存在且可写的目录 A。关闭、重新打开添加窗口，确认 A 恢复；再选目录 B 并重复确认。
3. 用有权下载的独立测试磁力和种子分别创建任务，核对日志、任务保存目录及实际文件。测试至少两个存储卷、中文和含空格目录。
4. 切回默认目录，确认新任务由下载器默认设置决定；原任务和文件不得被移动。
5. 重启桥接并确认目录偏好、密码、端口保留；修改端口/密码后也确认目录偏好仍在。
6. MoviePilot 提交一个专用测试任务，确认 savepath 与 MoviePilot 配置一致。代理不应改写上游路径。
7. 确认日志文件为 bridge.log、bridge.log.1–3，长期运行不无限增长。
8. 仅在确认回滚方式和已有配置备份后验证卸载：分别选择保留和清理；媒体库、下载文件及原生任务必须保持不变。尚未做真实 fnOS 卸载测试。

目录可写性检测以桥接进程身份执行，不能替代原生下载器进程的 ACL 验证；真实任务仍需确认写入权限。

## 回滚

优先用附带的 0.2.5 回滚包手动降级（是否允许降级由 fnOS 决定）。如系统不允许降级，可在卸载向导明确选“保留”，备份桥接配置后重新安装；不要选择清理，也不要删除下载目录。0.2.5 会忽略新增 download_path 字段。

## 第二阶段边界

本版未修复原生僵尸任务、未调用未经验证的原生删除 API、未修改下载数据库。FPK 和 MoviePilot 删除仍可能只影响底层引擎，原生列表残留的限制保持。

JS 分析包已读，确认前端存在 appcgi.downloadcenter.task.delete 及 uid、ids、delete_files 参数，并发现系统鉴权通信线索；尚无 FPK 后端正规授权调用的验证结果。0.2.7 应在本版实机确认稳定后单独开始，先验证只读调用，再用专用测试任务验证删除。当前停在第一阶段交付。
