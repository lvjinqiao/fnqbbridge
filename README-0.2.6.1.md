# 0.2.6.1 手机目录选择补丁

修复可确认的缺陷：移除原生目录选择交互的15秒超时。用户可以停留在手机系统选择器中，直到主动确认或取消，不再因计时器先结束而丢弃返回结果。

兼容手机原生桥接可能返回的JSON序列化字符串和字符串数字成功码。仍只接受受支持结构中的绝对路径，不自动把显示名称或相对路径变成目录。

选择期间按钮禁用，避免重复打开多个选择器；完成或失败恢复按钮。已能工作的电脑目录选择流程保留。

已通过：SDK返回结构测试、延迟确认模拟测试（初始化完成后触发计时器，确认不会取消待选目录）、Go完整race回归、前端语法检查、x86_64静态编译和fnpack打包。

未完成真实飞牛手机App验证，不能保证此次故障仅由超时造成。若仍失败，需要失败提示或截图以区分SDK返回结构、原生授权和后端目录验证问题。升级后请关闭App内旧页面，再重新从桌面打开，确认底部0.2.6.1版本。

本补丁未修改原生删除机制，0.2.7删除专项仍未开始。
